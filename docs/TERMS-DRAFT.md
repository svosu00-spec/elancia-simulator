# 학습용 로컬 시뮬레이터 이용 안내 초안

## 학습과 실습

이 프로젝트는 게임 패킷, 클라이언트·서버 통신, 월드 상태 저장을 공부하기 위한 비공식 실습 자료입니다. 테스트 캐릭터로 동작을 재현하고, 요청과 응답을 비교하며 서버 코드가 상태를 어떻게 바꾸는지 살펴볼 수 있습니다. 사용 권한이 있는 클라이언트와 자료를 준비해 본인 PC의 루프백 주소 `127.0.0.1`에서만 실습하세요. 테스트 계정에는 실습 전용 ID와 비밀번호를 사용합니다.

## 이용 범위

외부 사용자가 접속할 수 있도록 서버를 열거나 공개·상업 서비스로 운영하지 마세요. 공유기 포트포워딩, 공개 터널, 외부 서버에 배포하는 방식도 이 안내의 사용 범위를 벗어납니다. 패킷 실습에는 사용 권한이 있는 기록이나 직접 만든 예시만 사용합니다.
