# 로컬 실습 데이터 안내 초안

실습 전용 계정을 만들고, 본인 PC에서 생성한 예시 데이터로 기능을 확인합니다. 공식 게임이나 다른 서비스에서 쓰는 ID와 비밀번호는 입력하지 마세요.

| 위치 | 저장될 수 있는 데이터 |
| --- | --- |
| `data\` | 로컬 계정 ID, 비밀번호 검증용 해시·솔트, 세션 검증 정보, 캐릭터 상태, 로컬 인증서 |
| `logs\` | 실행 오류, 접속·월드 처리 로그 |
| `ElanciaRecorder\captures\` | 패킷 시각과 opcode, 개체 식별 정보, 허용된 범위의 대화 본문 |

패킷 기록에는 귓말이나 1:1 대화가 포함될 수 있습니다. 공개 이슈나 공유 문서에는 예시 데이터를 쓰고, 계정 DB·인증서·원본 기록은 실습 PC에서 보관합니다. 실습을 마치면 필요 없는 기록과 백업을 정리하세요.
